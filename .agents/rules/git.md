# Reglas de Git y Versionado

1. Queda estrictamente PROHIBIDO ejecutar `git push` o subir cambios a un repositorio remoto.
2. Queda prohibido realizar `git commit` sin la aprobación explícita y confirmada del usuario.
3. Antes de solicitar un commit, se debe:
   - Mostrar el resultado de `git status` y `git diff`.
   - Verificar que los cambios no incluyan secretos, tokens o credenciales.
   - Explicar detalladamente qué archivos fueron modificados y por qué.
4. El control final del historial de Git lo mantiene siempre el usuario.
