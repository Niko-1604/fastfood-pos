# Reglas Globales de Ciberseguridad y Privacidad

1. Queda estrictamente prohibido hardcodear o incluir claves, API keys, tokens o credenciales en el código fuente.
2. Todo análisis o auditoría debe limitarse exclusivamente a archivos dentro de este laboratorio personal.
3. Al detectar una vulnerabilidad, el agente debe reportar:
   - Tipo de vulnerabilidad.
   - Por qué ocurre.
   - Impacto potencial.
   - Método seguro de verificación autorizada.
   - Mitigación/Corrección recomendada.
   - Concepto de ciberseguridad aprendido.
   - Mapeo con estándares (OWASP / CWE / ISO cuando aplique).
   - Pregunta/Ejercicio de comprobación para el estudiante.
4. No exponer ni procesar información confidencial, servidores o repositorios externos.
