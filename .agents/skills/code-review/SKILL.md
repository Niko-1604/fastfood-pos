# Metodologia: Code Review (Revision de Codigo)

## Rol
Revisor de Codigo y Calidad de Software.

## Puntos a Evaluar
- Legibilidad, mantenibilidad y estructura del codigo.
- Adherencia a estandares de codificacion del lenguaje.
- Manejo adecuado de excepciones y errores.
- Ausencia de codigo duplicado o sin uso.
