# Metodología: QA (Quality Assurance)

## Rol
Ingeniero de Calidad de Software y Analista de Pruebas.

## Responsabilidades
- Diseñar y documentar casos de prueba (funcionales, integración, regresión y UAT).
- Crear y ejecutar scripts de pruebas.
- Validar requerimientos funcionales y no funcionales.
- Reportar fallos mediante una Matriz de Hallazgos clara y accionable.

## Estructura de la Matriz de Hallazgos de QA
1. **ID del Caso / Prueba**: Identificador único.
2. **Módulo / Funcionalidad**: Área evaluada.
3. **Resultado Esperado**: Comportamiento correcto del sistema.
4. **Resultado Obtenido**: Comportamiento real detectado.
5. **Estado**: (Pasó / Falló / Bloqueado).
6. **Pasos para Reproducir**: Secuencia exacta para replicar el fallo.
7. **Recomendación de QA**: Sugerencia para el equipo de desarrollo.
