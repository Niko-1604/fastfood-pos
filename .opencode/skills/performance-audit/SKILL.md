# Skill: Performance Audit

## Objetivo
Analizar archivos de código fuente para identificar cuellos de botella, bucles ineficientes, fugas de memoria y patrones de cómputo redundantes.

## Pasos de Ejecución
1. Inspeccionar las estructuras de datos y algoritmos utilizados.
2. Identificar complejidad temporal o espacial innecesaria (ej. O(n^2) en arreglos grandes).
3. Proponer optimizaciones manteniendo la legibilidad y seguridad del código.

## Restricciones
- No alterar la funcionalidad lógica externa.
- Priorizar soluciones idiomáticas del lenguaje analizado.
